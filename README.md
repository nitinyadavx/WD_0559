## 📖 About This Repository

This repository serves as a practical log of my progress through the **Web Design Workshop** as part of my B.Tech CSE coursework at ABES Engineering College. It acts as a digital portfolio for college assignments, hands-on lab experiments, and independent HTML/CSS explorations.

The core objective is to transition from theoretical concepts to production-ready front-end code, focusing on clean architecture, semantic markup, and responsive design principles. **New experiments are continuously integrated as the semester progresses.**

<br />

## 🛠️ Tech Stack & Tools

*   **Core Languages:** HTML5
*   **Version Control:** Git & GitHub
*   **CI/CD Automation:** GitHub Actions (Automated repository indexing)
*   **Visual Assets:** Shields.io, Readme Typing SVG, Capsule Render

<br />

## 🗂️ Project Structure

```text
WD_0559/
├── Exams/                  # Mid-term and practical exam submissions

├── Experiment 2/           # Text formatting, lists, and semantic elements

├── Experiment 5/           # Building interactive HTML forms and input validation
├── Experiment 6/           # Advanced layouts and multimedia embedding

```

## 💻 Local Setup

To view the source code or run these experiments locally, you do not need any complex build tools. A standard web browser is sufficient.

**1. Clone the repository:**
```bash
git clone [https://github.com/nitinyadavx/WD_0559.git](https://github.com/nitinyadavx/WD_0559.git)
```

**2. Navigate to the directory:**
```bash
cd WD_0559
```

**3. Run the files:**
Open any `.html` file inside the experiment folders directly in your preferred web browser (Chrome, Firefox, Edge, etc.).

<br />

## 🎯 Learning Outcomes

By the completion of these workshop modules, the following competencies are established:

*   **Structural Integrity:** Constructing well-formed, semantic HTML5 pages that adhere to modern web standards.
*   **Code Maintainability:** Writing readable, appropriately indented code with consistent naming conventions.
*   **Accessibility (a11y):** Implementing logical DOM flows, descriptive alt-text for media, and accessible form labels.
*   **Version Control Mastery:** Managing iterative coursework, branching, and automated workflows using Git and GitHub.
